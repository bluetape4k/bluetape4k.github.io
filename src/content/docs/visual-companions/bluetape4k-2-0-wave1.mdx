## Image Intelligence: facts, states, policy, and privacy

The pipeline qualifies multipart input, creates one immutable image, fans out to OCR, detection, and ZXing lanes, preserves explicit result states, and separates `VisitorPassPolicy` decisions from application-owned rendering and storage effects.

## AWS SQS: bounded batch and partial acknowledgement

The sequence shows one bounded `ReceiveMessage` batch, independent item handling, selective acknowledgement at the delete boundary, failed-item redelivery, cancellation precedence, and low-cardinality observation. Retry, DLQ, visibility timeout, and backoff remain caller-owned policy.

![AWS SQS bounded batch handling and partial acknowledgement](/assets/visual-companions/wave1/aws-sqs-reliability-en.png)

## Projects NearJCache: explicit L1/L2 semantics

The architecture keeps the Caffeine L1 front and Redis L2 back visible. Read hit/miss and fill, write-through, epoch-gated clear, bounded bulk policies, tier-separated statistics, JMX opt-in, and disabled-mode cost bounds are shown as separate contracts.
