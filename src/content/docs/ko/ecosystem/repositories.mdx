## 핵심 라이브러리

<div class="bt4k-repo-grid">
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-projects">
    <small>기반</small>
    <strong>bluetape4k-projects</strong>
    <span>주요 Kotlin/JVM backend library set입니다. Core utility, coroutine helper, data/infrastructure module, Spring Boot support, virtual-thread experiment, validation, logging, test foundation을 포함합니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-exposed">
    <small>영속성</small>
    <strong>bluetape4k-exposed</strong>
    <span>Repository pattern, JDBC/R2DBC support, cache-backed access, serialization helper, custom column type, Spring Boot auto-configuration을 위한 JetBrains Exposed extension입니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-aws">
    <small>Cloud 통합</small>
    <strong>bluetape4k-aws</strong>
    <span>AWS SDK v2와 AWS Kotlin SDK wrapper입니다. Coroutine-first API, Spring Boot 4 auto-configuration, Ktor 3 예제, common AWS client adapter를 제공합니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-graph">
    <small>Graph data</small>
    <strong>bluetape4k-graph</strong>
    <span>Neo4j, Memgraph, Apache AGE, TinkerPop, FalkorDB를 위한 graph database integration과 Testcontainers coverage가 있는 graph-backed service 예제입니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-leader">
    <small>운영</small>
    <strong>bluetape4k-leader</strong>
    <span>Blocking, async, coroutine, virtual-thread execution을 위한 distributed leader election API입니다. Redis, database, MongoDB, Hazelcast, ZooKeeper, Ktor, Spring Boot 예제를 포함합니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-dependencies">
    <small>버전 기반</small>
    <strong>bluetape4k-dependencies</strong>
    <span>Kotlin, Spring Boot, Exposed, Jackson, Ktor, AWS, Testcontainers와 공통 dependency family를 조직 전체에서 맞추기 위한 중앙 BOM과 version governance source입니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-text">
    <small>Text processing</small>
    <strong>bluetape4k-text</strong>
    <span>한국어/일본어 tokenizer, language detection, Aho-Corasick style search, backend text enrichment pipeline을 위한 Kotlin/JVM text processing module입니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-image">
    <small>Image processing</small>
    <strong>bluetape4k-image</strong>
    <span>scrimage, libvips/JNI 또는 FFM path, TwelveMonkeys, fixture, Spring Boot integration을 사용하는 backend media workflow용 image processing module입니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-javers">
    <small>Audit와 diff</small>
    <strong>bluetape4k-javers</strong>
    <span>Kotlin service를 위한 Javers audit/diff toolkit입니다. Redis/Kafka persistence support와 change history use case를 위한 Exposed integration을 포함합니다.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-experimental">
    <small>Incubation</small>
    <strong>bluetape4k-experimental</strong>
    <span>새 platform version, migration candidate, library idea를 stable module로 옮기기 전에 검증하는 Kotlin, Java, Spring Boot experimental module입니다.</span>
  </a>
</div>
