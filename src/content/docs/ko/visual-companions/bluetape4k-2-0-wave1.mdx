## AWS SQS: bounded batch와 부분 acknowledgement

하나의 제한된 `ReceiveMessage` batch를 독립 항목으로 처리하고, delete 경계에서 성공 항목만 acknowledgement합니다. 실패 항목 redelivery, cancellation 우선순위, low-cardinality observation을 함께 표시하며 retry·DLQ·visibility timeout·backoff는 caller 정책으로 남깁니다.

## Projects NearJCache: 명시적인 L1/L2 의미론

Caffeine L1 front와 Redis L2 back을 숨기지 않고 드러냅니다. read hit/miss와 fill, write-through, epoch 기반 clear, bounded bulk policy, tier별 statistics, JMX opt-in, disabled mode의 비용 제한을 각각의 계약으로 표시합니다.
