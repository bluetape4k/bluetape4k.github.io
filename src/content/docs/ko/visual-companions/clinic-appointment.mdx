이 시각 자료는 병원 예약 서비스의 복잡한 업무 규칙을 더 쉽게 살펴보도록 돕습니다. 구현 기준인 Markdown 설계 문서를 대체하지는 않습니다.

현재 두 자료는 모두 `hybrid` 표현 방식을 사용합니다.

- 기본 화면인 `simulation`은 승인된 설계가 어떻게 작동하는지 설명합니다.
- `history`는 현재 설계가 만들어진 과정과 관련 변경 사항을 보여 줍니다.

게시된 파일은 clinic 커밋 [`6967e38`](https://github.com/bluetape4k/clinic-appointment/commit/6967e385bf92a40619a9bbe17f96da182ac8bd50)을 기준으로 생성한 오프라인 스냅숏입니다. Pages를 빌드할 때마다 원본 파일과 동일한지 검증합니다.
