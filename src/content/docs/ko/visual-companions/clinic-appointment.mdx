이 시각 자료는 병원 예약 서비스의 복잡한 업무 규칙을 더 쉽게 살펴보도록 돕습니다. 규범 문서인 Markdown 설계를 대체하지는 않습니다.

현재 두 자료는 모두 `hybrid` 표현 방식을 사용합니다.

- 기본 화면인 `simulation`은 승인된 설계가 어떻게 작동하는지 설명합니다.
- `history`는 설계가 현재 모습에 이른 이유와 근거 변경을 보여줍니다.

게시된 파일은 clinic commit [`85a09e4`](https://github.com/bluetape4k/clinic-appointment/commit/85a09e4ba16644219c15e91d94c5a4ccb7619a64)에 고정된 offline snapshot입니다. 모든 Pages build에서 파일 byte를 검증합니다.
