이 시각 자료는 병원 예약 서비스의 복잡한 상품·예약 업무 규칙을 더 쉽게 살펴보도록 돕습니다. 구현 기준인 Markdown 설계 문서를 대체하지는 않습니다.

현재 여섯 개의 영문·한글 시각 자료가 게시되어 있습니다. 두 개의 기반 자료는 `hybrid`, 프로필 자료와 Issue #184 상품 자료는 `simulation` 표현 방식을 사용합니다.

- `simulation`은 선택에 따라 승인된 설계가 어떻게 작동하는지 설명합니다.
- `history`는 두 개의 기반 자료에서 현재 설계가 만들어진 과정과 관련 변경 사항을 보여 줍니다.

게시된 파일은 clinic 커밋 [`e974333`](https://github.com/bluetape4k/clinic-appointment/commit/e9743337cdc1bf499af68e4e94a9f06b2833d838)을 기준으로 생성한 오프라인 스냅숏입니다. Pages를 빌드할 때마다 원본 파일과 동일한지 검증합니다.
