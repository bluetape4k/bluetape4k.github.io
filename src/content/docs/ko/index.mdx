## BOM부터 시작하기

```kotlin
dependencyManagement {
    imports {
        mavenBom("io.github.bluetape4k:bluetape4k-dependencies:1.1.1")
        mavenBom("io.github.bluetape4k:bluetape4k-bom:1.9.0")
    }
}
```

먼저 중앙 dependency BOM을 추가하고, bluetape4k core BOM과 서비스에 필요한 library를 이어서 추가합니다.
