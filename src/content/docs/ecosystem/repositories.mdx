## Core Libraries

<div class="bt4k-repo-grid">
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-projects">
    <small>Foundation</small>
    <strong>bluetape4k-projects</strong>
    <span><em>Latest release: 1.12.1.</em> The main Kotlin/JVM backend library set. It contains core utilities, coroutine helpers, data and infrastructure modules, Spring Boot support, virtual-thread experiments, validation, logging, and test foundations used by other bluetape4k repositories.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-exposed">
    <small>Persistence</small>
    <strong>bluetape4k-exposed</strong>
    <span><em>Latest release: 1.12.1.</em> JetBrains Exposed extensions for repository patterns, JDBC/R2DBC support, cache-backed access, serialization helpers, custom column types, and Spring Boot auto-configuration.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-aws">
    <small>Cloud integration</small>
    <strong>bluetape4k-aws</strong>
    <span><em>Latest release: 0.5.0.</em> AWS SDK v2 and AWS Kotlin SDK wrappers with coroutine-first APIs, Spring Boot 4 auto-configuration, Ktor 3 examples, and service-oriented adapters for common AWS clients.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-graph">
    <small>Graph data</small>
    <strong>bluetape4k-graph</strong>
    <span><em>Latest release: 0.6.0.</em> Graph database integrations for Neo4j, Memgraph, Apache AGE, TinkerPop, FalkorDB, and graph-backed service examples with Testcontainers coverage.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-leader">
    <small>Operations</small>
    <strong>bluetape4k-leader</strong>
    <span><em>Latest release: 0.5.0.</em> Distributed leader election APIs for blocking, async, coroutine, and virtual-thread execution. Includes Redis, database, MongoDB, Hazelcast, ZooKeeper, Ktor, and Spring Boot examples.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-dependencies">
    <small>Version base</small>
    <strong>bluetape4k-dependencies</strong>
    <span><em>Latest release: 2.0.0.</em> The central BOM and shared version governance source for Kotlin, Spring Boot, Exposed, Jackson, Ktor, AWS, Testcontainers, and common dependency families across the organization.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-text">
    <small>Text processing</small>
    <strong>bluetape4k-text</strong>
    <span><em>Latest release: 0.3.0.</em> Kotlin/JVM text processing modules for Korean and Japanese tokenizers, language detection, Aho-Corasick style search, and backend text enrichment pipelines.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-image">
    <small>Image processing</small>
    <strong>bluetape4k-image</strong>
    <span><em>Latest release: 0.4.0.</em> Image processing modules built around scrimage, libvips/JNI or FFM paths, TwelveMonkeys, fixtures, and Spring Boot integration for backend media workflows.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-javers">
    <small>Audit and diff</small>
    <strong>bluetape4k-javers</strong>
    <span><em>Latest release: 0.3.0.</em> Javers auditing and diff toolkit for Kotlin services, including Redis and Kafka persistence support plus Exposed integration for change history use cases.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-experimental">
    <small>Incubation</small>
    <strong>bluetape4k-experimental</strong>
    <span>Experimental Kotlin, Java, and Spring Boot modules used to test new platform versions, migration candidates, and library ideas before they become stable modules.</span>
  </a>
</div>
