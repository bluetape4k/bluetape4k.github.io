## Library Repositories

<div class="bt4k-repo-grid">
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-projects">
    <strong>bluetape4k-projects</strong>
    <span>Core Kotlin/JVM backend libraries, coroutine support, data, infrastructure, Spring Boot, and virtual-thread modules.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-exposed">
    <strong>bluetape4k-exposed</strong>
    <span>JetBrains Exposed extensions for JDBC/R2DBC repositories, caching, serialization, and Spring Boot auto-configuration.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-aws">
    <strong>bluetape4k-aws</strong>
    <span>AWS SDK v2 and AWS Kotlin SDK wrappers with coroutine, Spring Boot 4, and Ktor 3 support.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-graph">
    <strong>bluetape4k-graph</strong>
    <span>Graph integrations for Neo4j, Memgraph, Apache AGE, TinkerPop, FalkorDB, and related examples.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-leader">
    <strong>bluetape4k-leader</strong>
    <span>Distributed leader election APIs for blocking, async, coroutine, virtual-thread, Redis, and service examples.</span>
  </a>
  <a class="bt4k-repo" href="https://github.com/bluetape4k/bluetape4k-dependencies">
    <strong>bluetape4k-dependencies</strong>
    <span>Central BOM and version governance for aligned dependency updates across bluetape4k repositories.</span>
  </a>
</div>
