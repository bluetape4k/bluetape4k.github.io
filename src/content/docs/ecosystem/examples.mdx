## Recommended Learning Path

1. Start with the central BOM in [Getting Started](/getting-started/).
2. Choose either Spring Boot or Ktor examples in the workshop repositories.
3. Add Exposed JDBC/R2DBC examples when persistence becomes the main concern.
4. Move to AWS, graph, leader election, or Timefold examples only after the base service shape is clear.
