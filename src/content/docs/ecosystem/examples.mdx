## Workshop Repositories

<div class="bt4k-example-grid">

  <a class="bt4k-example" href="https://github.com/bluetape4k/exposed-workshop">

  </a>
  <a class="bt4k-example" href="https://github.com/bluetape4k/exposed-r2dbc-workshop">

    <strong>exposed-r2dbc-workshop</strong>
    <span>Reactive and coroutine-oriented Exposed R2DBC examples with H2, PostgreSQL, MySQL, MariaDB, repositories, Spring WebFlux, Gatling, and migration-focused samples.</span>
  </a>
  <a class="bt4k-example" href="https://github.com/bluetape4k/timefold-workshop">
    <small>Optimization examples</small>
    <strong>timefold-workshop</strong>
    <span>Timefold Solver workshop examples for planning, scheduling, and optimization problems. Useful for understanding solver-driven backend workflows.</span>
  </a>
  <a class="bt4k-example" href="https://github.com/bluetape4k/clinic-appointment">
