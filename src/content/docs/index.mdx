## What bluetape4k Provides

<div class="bt4k-feature-grid">
  <a class="bt4k-feature" href="/ecosystem/repositories/">
    <strong>Application edge</strong>
    <span>Spring Boot and Ktor foundations for HTTP APIs, coroutine-first execution, WebFlux/MVC examples, and request flows.</span>
  </a>
  <a class="bt4k-feature" href="/ecosystem/repositories/">
    <strong>Persistence</strong>
    <span>Exposed JDBC/R2DBC repositories, cache-backed data access, serialization, and database examples that keep persistence code consistent.</span>
  </a>
  <a class="bt4k-feature" href="/ecosystem/repositories/">
    <strong>Integration</strong>
    <span>AWS SDK wrappers, Redis/Kafka patterns, graph database integrations, and infrastructure helpers for services that cross system boundaries.</span>
  </a>
  <a class="bt4k-feature" href="/ecosystem/repositories/">
    <strong>Operations</strong>
    <span>Leader election, scheduling gates, observability examples, virtual-thread experiments, and runtime coordination patterns.</span>
  </a>
  <a class="bt4k-feature" href="/ecosystem/repositories/">
    <strong>Domain utilities</strong>
    <span>Text processing, image pipelines, validation, logging, testing, coroutine helpers, and reusable Kotlin/JVM building blocks.</span>
  </a>
  <a class="bt4k-feature" href="/ecosystem/examples/">
    <strong>Working examples</strong>
    <span>Workshops and sample applications for Spring Boot, Ktor, R2DBC, Exposed, Timefold, scheduling, observability, and production-style backend flows.</span>
  </a>
</div>

## Start With The BOM

```kotlin
dependencies {
    implementation(platform("io.github.bluetape4k:bluetape4k-dependencies:1.2.0"))
    implementation("io.github.bluetape4k:bluetape4k-core")
    implementation("io.github.bluetape4k:bluetape4k-coroutines")
}
```

Use the central dependency BOM first, then add the bluetape4k modules your service needs without module versions.
