## Start With The BOM

```kotlin
dependencyManagement {
    imports {
        mavenBom("io.github.bluetape4k:bluetape4k-dependencies:1.0.0")
    }
}
```

Use the central dependency BOM first, then add the module-specific BOMs and libraries your service needs.
