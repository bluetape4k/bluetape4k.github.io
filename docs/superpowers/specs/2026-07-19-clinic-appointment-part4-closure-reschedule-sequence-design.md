# Clinic Appointment Part 4 Closure Reschedule Sequence Diagram Design

## 목적

Part 4 독자가 휴진 재배정에서 예약별 후보를 만드는 경로와 Timefold Solver로 전체 배치를 비교하는 경로가 실제로 어디서 갈라지는지 한눈에 이해하도록 시퀀스 다이어그램을 추가한다.

## 범위

- 운영자가 휴진 재배정을 시작할 때 `ClosureRescheduleService`와 `SolverService` 중 어느 진입점을 선택하는지 표현한다.
- 빠른 후보 경로에서는 영향 예약 조회, `PENDING_RESCHEDULE` 전환과 이력 기록, 예약별 후보 계산·저장, 관리자 선택 또는 자동 선택, 새 예약 생성과 원본 예약의 `RESCHEDULED` 전환을 보여 준다.
- 전체 최적화 경로에서는 날짜 범위의 예약·의사·진료·장비·업무시간·휴진·공휴일 로딩, Timefold Solver 실행, 전체 점수와 배치안 반환을 보여 준다.
- 현재 `SolverService.optimizeReschedule()` 결과가 `ClosureRescheduleService`의 상태 전환·저장·알림 흐름과 자동으로 연결되지 않는다는 경계를 명시한다.

## 시각 설계

- Part 3 시퀀스 다이어그램과 같은 어두운 남색 배경과 음영이 낮은 청록·초록·황갈색 계열을 사용한다.
- 하나의 투명한 `alt` 프레임 안에서 빠른 후보 경로와 전체 최적화 경로를 위아래로 나눈다.
- 참여자, 생명선, 활성화 막대, 순번이 보이는 메시지 라벨을 사용하고 메시지 라벨과 선이 겹치지 않도록 행 높이를 충분히 확보한다.
- 기술 다이어그램만 `bt4k-architecture` 확대 대상으로 등록하고 한국어 제목을 제공한다.

## 배치

Part 4의 `휴진 재배정에서 두 경로가 갈라진다` 절에서 현재 텍스트 흐름 요약을 대체한다. 다이어그램 뒤의 설명은 빠른 후보 경로의 장점과 한계, Solver 경로의 운영상 추가 요구를 해석하는 역할을 맡는다.

## 완료 조건

- SVG와 2배 PNG가 생성된다.
- XML, 텍스트, 연결선, 끝점, 혼합 모서리, 시퀀스 스타일 검사를 통과한다.
- 원본 크기 PNG에서 라벨 겹침, 잘림, 낮은 대비, 불분명한 분기 경계가 없다.
- 로컬 Part 4 페이지에서 다이어그램 제목, 이미지, 크게 보기 기능이 정상 표시된다.
