# Clinic Appointment Part 3 Sequence Diagram Design

## 목적

Part 3 독자가 예약 가능 시간 조회가 여러 저장소와 업무 규칙을 어떤 순서로 통과하는지 한눈에 이해하도록 시퀀스 다이어그램을 추가한다.

## 범위

- 사용자, 예약 API, 예약 가능 시간 계산 서비스, 병원·의사·진료·예약·장비 저장소의 호출 관계를 표현한다.
- 공휴일·전일 휴진·의사 전일 부재처럼 하루 전체를 막는 조건은 조기 종료 분기로 표시한다.
- 유효 시간 범위 계산과 예약 후보 생성은 서비스 내부 처리로 표현한다.
- 후보별 최대 동시 진료 환자 수와 장비 점검·수량 검사는 반복 구간으로 표시한다.
- 전체 일정 최적화는 Part 4와 중복되지 않도록 Timefold Solver로 넘어가는 책임 경계만 주석으로 표시한다.

## 시각 설계

- 기존 Part 3 다이어그램과 같은 어두운 남색 배경과 청록·초록 강조색을 사용한다.
- 참여자 사이의 간격을 넉넉히 두어 메시지 라벨과 화살표가 겹치지 않게 한다.
- 정상 흐름은 청록색, 즉시 종료와 후보 제외는 붉은색, 최종 반환은 초록색으로 구분한다.
- 기술 다이어그램만 `bt4k-architecture` 확대 대상으로 등록하고 한국어 제목을 제공한다.

## 배치

기존 예약 가능 시간 계산 파이프라인 다음에 배치한다. 파이프라인이 계산의 단계와 시간 범위를 설명하고, 시퀀스 다이어그램은 실행 시 참여자 사이의 호출 순서를 설명하도록 역할을 나눈다.

## 완료 조건

- SVG와 2배 PNG가 생성된다.
- XML, 텍스트, 연결선, 끝점, 혼합 모서리, 시퀀스 스타일 검사를 통과한다.
- 원본 크기 PNG에서 라벨 겹침, 잘림, 낮은 대비가 없다.
- 로컬 Part 3 페이지에서 크게 보기 제목과 이미지가 정상 표시된다.
