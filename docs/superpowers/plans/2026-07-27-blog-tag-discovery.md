# 블로그 태그 탐색 확장 구현 계획

**목표:** 한·영 블로그 글 쌍에 동일한 명시 태그를 부여하고, 글 목록에서 인기 태그와 전체 태그를 모두 쉽게 탐색하게 한다.

**구조:** 기존 `resolveBlogTaxonomy`를 태그 slug와 다국어 label의 단일 기준으로 유지한다. 각 글의 `blog.tags`에는 한·영 쌍이 공유하는 명시 태그를 기록해 번역 문구 차이로 인한 분류 편차를 없앤다. 목록은 글 수 내림차순 인기 태그 12개와 label 오름차순 전체 태그를 분리하되, 모두 동일한 `?tag=` 필터 상태를 사용한다.

**기술:** Astro 6, Starlight, Node.js test runner, Playwright

---

## 1. 태그 계약 회귀 테스트

**파일**
- 수정: `tests/ecosystem/blog-taxonomy.test.mjs`

**작업**
- 멀티테넌시, 실전 예제, 비교, 테스트, 복원력, 관측성, 메시징, 트랜잭션, 보안, Ktor 태그의 추론과 다국어 label을 검증한다.
- 한·영 85개 파일명이 일치하고 모든 쌍의 `blog.tags` 배열이 동일한지 검증한다.
- 인기 태그와 전체 태그 UI, 정렬 기준, 태그 선택 시 상세 목록 자동 노출 계약을 검증한다.
- 테스트를 실행해 새 계약이 아직 구현되지 않아 실패하는지 확인한다.
