# Bluetape4k 생태계 개요도 추가 계획

## 목적

소개 시리즈 Part 1 독자가 Spring Boot 4·Ktor 3 서비스의 소유 경계와 Bluetape4k의 선택 가능한 책임 계층을 한눈에 파악하도록 한다. 이 그림은 실행 순서나 의존성 그래프가 아니라 책임 지도를 제공한다.

## 범위

- 한국어·영어 소개 글에 각각 지역화된 SVG/PNG 개요도를 삽입한다.
- 서비스 소유 애플리케이션 경계와 도메인 기능·데이터·인프라·기반 계층을 표현한다.
- 대표 이미지는 유지하고 확대 대상에서 제외한다.
- 기술 다이어그램으로 분류해 크게 보기 제목과 회귀 테스트를 추가한다.

## 실행과 검증

1. 기존 계층 표와 승인된 어두운 다이어그램 스타일을 근거로 SVG 원본을 만든다.
   - Expected DoD: 두 언어의 독립 SVG가 서비스 소유 경계와 선택 조합 원칙을 같은 구조로 전달한다.
2. CairoSVG로 PNG를 렌더링하고 SVG·텍스트·연결선 검사를 수행한다.
   - Expected DoD: XML과 유형별 감사가 통과하고, 원본 크기 PNG에서 카드·화살촉·여백이 읽기 쉽다.
3. 본문과 크게 보기 제목 테스트를 갱신하고 사이트 검증을 실행한다.
   - Expected DoD: 두 글의 그림이 확대 대상으로 인식되고 대표 이미지는 제외되며, 테스트·빌드·로컬 경로가 통과한다.
