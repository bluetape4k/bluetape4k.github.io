- [ ] **2단계: 루트 publishing 설정 근처에 결정적 export task 등록**

다음 task 본문을 그대로 추가한다. `isSampleOrBenchmarkProject()`는 publication에만 사용하고 문서화 범위에는 사용하지 않는다.

```kotlin
val manualModuleInventory = layout.buildDirectory.file("manual/module-inventory.json")

tasks.register("exportManualModuleInventory") {
    group = "documentation"
    description = "Exports the registered Gradle project inventory for manual validation."

    val repositoryRoot = project.rootDir.toPath()
    val modules = project.subprojects.sortedBy(Project::getPath).map { module ->
        val sourceDir = repositoryRoot.relativize(module.projectDir.toPath())
            .toString().replace(File.separatorChar, '/')
        val kind = when {
            sourceDir.startsWith("examples/") -> "example"
            sourceDir.startsWith("benchmark/") -> "benchmark"
            else -> "library"
        }
        linkedMapOf(
            "gradlePath" to module.path,
            "projectName" to module.name,
            "sourceDir" to sourceDir,
            "kind" to kind,
        )
    }
    val inventoryJson = groovy.json.JsonOutput.prettyPrint(groovy.json.JsonOutput.toJson(modules)) + "\n"
    inputs.property("inventoryJson", inventoryJson)
    outputs.file(manualModuleInventory)
    doLast {
        manualModuleInventory.get().asFile.apply {
            parentFile.mkdirs()
            writeText(inventoryJson)
        }
    }
}
```

```ruby
module ManualDocs
  SUPPORTED_SCHEMA_VERSION = 2
  REQUIRED_SECTIONS = %w[
    problem when-to-use coordinates concepts quick-start api-by-task
    patterns integrations configuration failures operations testing
    workshops limitations sources
  ].freeze
  VALID_KINDS = %w[library example benchmark].freeze

  class Validator
    attr_reader :errors
    def initialize(inventory:, manifest_path:, repository_root:, expected_release:)
      @inventory = inventory
      @manifest_path = File.expand_path(manifest_path)
      @repository_root = File.expand_path(repository_root)
      @expected_release = expected_release
      @errors = validate.sort
    end
  end

  class ReleaseContract
    ValidationResult = Struct.new(:errors, :checked_count, keyword_init: true)
    def initialize(repository_root:, tag:, expected_sha:, git_runner: nil); end
    def validate; end
    def errors = validate.errors
  end
end
```

1. `core` and `dao` establish entity, ID, mapping, and repository concepts.
2. JDBC is the production default when a blocking driver and transaction manager own the boundary.

5. Database adapters refine dialect-specific behavior; they do not replace the JDBC/R2DBC foundation.

7. `bluetape4k-javers` owns audit/history concerns rather than overloading persistence repositories.

예상 결과: 모든 명령이 종료 코드 0으로 끝난다. 프로덕션 코드가 변경되지 않았으므로 전체 Kotlin 테스트는 불필요하며, Gradle 설정/인벤토리 검증과 문서 계약만 실행한다.

- [ ] **5단계: 릴리스 메타데이터를 포함한 소스 PR 생성**

`develop`을 대상으로 issue/PR을 생성하고 둘 다 `debop`에게 할당하며, `1.11.0` milestone과 복사한 label을 적용한다. 최종 PR 본문 섹션이 정확히 `## DoD Status`인지 확인한다. 숫자 placeholder를 남기지 말고 live 수치를 기록한다.

```bash
ISSUE_URL="$(gh issue create --title 'Publish the release-faithful Exposed 1.11 manual' --body 'Create the bilingual source-of-truth manual for all 40 projects in release 1.11.0.' --assignee debop --milestone 1.11.0)"
ISSUE_NUMBER="${ISSUE_URL##*/}"
PR_URL="$(gh pr create --base develop --head docs/exposed-1.11-manual --title 'Publish the Exposed 1.11 source manual' --assignee debop --milestone 1.11.0 --body "Closes #${ISSUE_NUMBER}

## Summary

Publishes the bilingual, release-faithful Exposed 1.11 manual and its executable validation contract.

## DoD Status

- [x] 40 stable projects covered in English and Korean
- [x] release provenance and links validated
- [x] diagrams passed checklist and full-size review")"
PR_NUMBER="${PR_URL##*/}"
gh issue view "$ISSUE_NUMBER" --json labels --jq '.labels[].name' | while IFS= read -r label; do gh pr edit "$PR_NUMBER" --add-label "$label"; done
gh issue view "$ISSUE_NUMBER" --json assignees,labels,milestone,state
gh pr view "$PR_NUMBER" --json assignees,labels,milestone,body,headRefName,baseRefName
gh pr checks "$PR_NUMBER" --watch
```

live CI가 green이 될 때까지 merge하지 않는다. merge 후 병합된 소스 커밋을 기록하고, 해당 정확한 커밋을 웹사이트 snapshot 입력으로 사용한다.
