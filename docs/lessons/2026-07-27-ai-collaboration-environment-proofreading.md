# AI 협업 환경 글과 다이어그램 교정 교훈

## 범위

- `ai-collaboration-environment.mdx` 한영 문서
- AI 협업 과정 한영 다크 스타일 다이어그램
- 다이어그램 크게 보기 제목과 대표 이미지 제외 규칙

## 교정 교훈

### 기술 다이어그램과 대표 이미지는 역할이 다르다

기술 다이어그램은 본문의 구조와 상호 작용을 설명하므로 언어별 레이블,
확대 제목, SVG 원본이 필요하다. 반면 대표 이미지는 글의 시각적 식별을
담당하므로 같은 확대 동작을 적용하면 독자가 기대하는 상호 작용이
흐려진다. 글의 모든 이미지를 일괄 처리하지 않고 독자가 정보를 읽는
기술 그림만 크게 보기 대상으로 분류해야 한다.

### 한국어 판은 이미지 내부까지 번역한다

본문과 캡션만 한국어로 바꾸고 다이어그램의 단계명과 연결선 레이블을
영어로 남기면 독자는 그림을 읽을 때 언어를 전환해야 한다. 제목, 단계,
행동, 설명 메모는 한국어로 제공하되 API 이름과 코드 식별자는 그대로
유지한다. 한영 자산을 분리하면 번역 길이에 맞춰 카드 폭과 간격도 각각
검증할 수 있다.

## 검증

- 한영 SVG XML과 PNG 렌더링 확인
- 연결선 기하·끝점·교차 검사
- 기술 다이어그램 확대 제목과 대표 이미지 제외 규칙 확인
- 사이트 테스트와 정적 빌드
