# dependencies 2.0.0 시리즈 문구 교정 lesson

## 맥락

Part 4의 운영 안전성 설명에서 알 수 없는 상태를 정상 상태처럼 보여 주지 않는다는 표현을 사용했다. 사용자는 이를 `모르는 상태를 정상처럼 취급하지 않는다`로 고쳐 달라고 요청했다.

## 놓친 판단

처음 문구는 화면에 어떻게 보이는지에 초점을 두어, `UNKNOWN`과 손상된 이력에 정상 상태의 의미를 부여하지 않아야 한다는 기술 계약을 충분히 드러내지 못했다. 본문만 고친 뒤 구현 계획의 같은 제목을 다시 확인하지 않아 문서 간 추적성도 어긋났다.

## 결정과 결과

- 독자에게 보이는 표현이 아니라 시스템의 상태 판정 계약을 설명하도록 `모르는 상태를 정상처럼 취급하지 않는다`를 사용한다.
- 사용자가 확정한 문구는 본문뿐 아니라 설계·계획·테스트·시리즈 탐색처럼 같은 계약을 참조하는 모든 표면에서 검색한다.
- 의미가 다른 `UNKNOWN`, 손상된 영속 이력, 런타임 객체, 직렬화 데이터를 하나의 정상/비정상 표현으로 뭉개지 않는다.

## 재발 방지

사용자 문구 교정을 반영한 뒤 이전 문구와 새 문구를 저장소 전체에서 함께 검색한다. 이전 문구가 남아 있으면 단순한 사본인지, 의도적으로 보존한 인용인지 확인하고, 같은 기술 계약을 가리키는 문서라면 함께 수정한다.
