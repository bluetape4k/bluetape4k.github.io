## 사실과 경계 검증

- Spring Boot 4의 Jackson 3 전환은 의존성 좌표, 패키지 네임스페이스, 매퍼 자동 구성, 호환 속성, 아직 Jackson 2에 남아 있는 통합 지점을 나누어 설명해야 한다.
- `spring.jackson.use-jackson2-defaults=true`는 Jackson 2를 다시 활성화하는 설정이 아니다. Jackson 3 매퍼에 Jackson 2와 유사한 기본값을 적용하는 호환 속성이라는 의미를 유지해야 한다.
- HTTP 전송 계층의 본문 크기 제한과 이미 `String`으로 만들어진 입력을 서비스에서 검사하는 작업은 서로 다른 경계다. 후자의 검사만으로 네트워크 수신 비용이나 메모리 할당을 방지했다고 설명해서는 안 된다.
- 언어 감지는 확률적 판단이다. 알 수 없는 언어, 신뢰도가 낮은 결과, 여러 언어가 섞인 입력을 어떻게 처리할지는 감지 라이브러리가 아니라 애플리케이션 정책이 결정한다.
- 설명용 의사코드와 애플리케이션 정책은 라이브러리가 실제로 제공하는 공개 API와 구분했다.

## 한국어 교정 교훈

- `root build`, `workshop source`, `phrase extraction`처럼 식별자가 아닌 일반 설명은 각각 `루트 빌드`, `워크숍 소스`, `구 추출`처럼 기술 문맥에 맞는 한국어로 쓴다.
- “억지로 포장하지 말고” 같은 구어적 평가는 제거하고, 호환 계층이 보장하는 범위와 별도로 검증해야 할 항목을 직접 설명한다.
- 독자용 자료에는 대표 모듈 README, 워크숍, 예제 소스처럼 이해와 재현에 필요한 링크를 남긴다. 내부 품질 보고서, 작업 계획, 이슈 원문처럼 독자의 학습에 직접 필요하지 않은 자료는 제외한다.
- 번역어를 기계적으로 늘리기보다 `Jackson`, `Spring Boot`, `Lingua`, `API` 같은 고유 기술명은 유지하고, 그 주변의 일반 서술을 자연스러운 기술 한국어로 다듬는다.

## 다이어그램 교훈

- 정적 감사 통과만으로 시각 품질이 보장되지는 않는다. 원본 크기 확인에서 영어 카드 제목이 경계를 넘는 문제를 발견해 글꼴 크기와 여백을 조정했다.
- 하나의 분기점에서 여러 연결선이 같은 구간을 공유하면 각 화살표의 출발과 의미가 모호해진다. 서로 다른 포트를 사용하도록 시작점을 분리해 `shared_segments=0`을 확보했다.
- KO/EN 자산은 카드 위치와 연결 구조를 동일하게 유지하되, 언어별 문자열 길이에 맞춰 글꼴 크기를 따로 조정할 수 있다.
- SVG, CairoSVG 2배 PNG, connector·endpoint·geometry·corner 감사, 원본 크기 육안 검사를 모두 통과해야 배치 다이어그램을 완료로 기록한다.

- 언어 감지 결과의 불확실성과 애플리케이션 정책 책임, 의사코드와 실제 공개 API의 구분 규칙을 추가했다.
