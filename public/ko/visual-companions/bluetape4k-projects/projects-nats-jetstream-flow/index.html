NATS JetStream Flow: 하나의 cold 계약과 두 개의 입력 경로

ConsumerContext pull과 JetStream push가 하나의 bounded Flow<Message>로 합쳐지는 과정을 재생하고 caller 소유 acknowledgement, redelivery, drop, cancellation, terminal completion을 따라갑니다.

Cold는 collect할 때 adapter handle이 만들어진다는 뜻이며 library는 message를 자동 ack하지 않습니다.

capacity 1..1,024
pending ≤ 65,536 messages
pending ≤ 64 MiB

Adapter가 소유

adapter는 cold bridge, bounded channel, pending/drop 관찰, blocking receive interrupt, 자신이 만든 JetStreamSubscription 또는 IterableConsumer cleanup을 소유합니다.

Caller가 소유

caller는 connection lifecycle, stream과 durable-consumer 생성, PublishAck 해석, ack/nak/term, retry/backoff, idempotency, metric, 외부 authorization을 소유합니다.
